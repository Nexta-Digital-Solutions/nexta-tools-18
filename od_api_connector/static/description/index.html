Odoo API Connector

This module is base module for Odoo Dynamic API & Webhook Manager.

Note: Below features only works when you have Odoo Dynamic API & Webhook Manager module.

Features

  • 🔄 Manage Odoo through APIs — Create, Update, Search, Count, Copy, and Delete records using secure API requests from another system.
  • ⚡ Customizable Payload & Response — Easily adapt the request and response structure to match the requirements of your external systems.
  • 🛠 Run Server Actions Remotely — Trigger Odoo server actions from another system to execute custom code or perform any operations.
  • 🌐 Dynamic Endpoint Handling — Define, manage, and process API endpoints dynamically with minimal setup.
  • 🖥 User-Friendly Interface — Configure API handlers and map responses effortlessly through an intuitive Odoo interface.
  • 📝 Configurable loggers — capable of recording every request and its corresponding response.
